KNOCKDESK SCI-FI SFX PACK — 10 sounds (JARVIS / HUD style)
=======================================================
Format: WAV 48 kHz / 24-bit stereo (master quality) + MP3 320k folder (phone / CapCut ke liye)
License: Original sounds, khud generate kiye gaye — commercial use (ads, YouTube, KnockDesk) bilkul free.

FILE                              KAHAN USE KAREIN
01_system_boot                    App khulna / jaagna — power-up riser + "online" hit (~2.4s par hit)
02_hologram_panel_open            Panel / window / HUD khulna (hit ~0.2s par)
                                  -> Panel BAND: isi file ko editor mein REVERSE kar dein
03_data_scan                      Scan, analysis, data processing, telemetry readout
04_ui_click                       Click / button / typing
                                  -> Hover: isi ko -10 dB volume par lagayein
                                  -> Typing: baar baar lagayein, har copy ka pitch thoda upar/neeche
05_access_granted                 Tasdeeq / kamyabi / task complete
06_soft_error                     Narm ghalti / access denied
07_voice_ai_listening             Mic on / AI sun raha hai / wake word
08_ai_processing_LOOP             AI soch raha hai — 4 sec seamless loop, jitni der chahiye repeat
09_notification                   Notification / soft alert ping
10_room_tone_ambience_LOOP        Peeche ka mahaul — 12 sec seamless loop, poori video ke neeche halka

TIPS
- Room tone (10) ko -15 se -20 dB par rakhein, dialogue/voice ke neeche.
- Processing loop (08) ko voice ke dauraan -8 dB tak neeche kar dein.
- Loops (08, 10) ke liye WAV hi use karein — MP3 mein loop ke jod par halki si gap aa sakti hai.
- Ek hi sound baar baar lag rahi ho to har copy ka pitch +/- 1-2 semitone badal dein — natural lagega.
